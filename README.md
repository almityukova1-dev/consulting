# Сайт-визитка: автоматизация бизнеса в ОАЭ

Статический одностраничный сайт (HTML + CSS + JS, без сборки). Публикуется через GitHub Pages.

## Структура

- `index.html` — главная страница
- `styles.css` — стили
- `script.js` — меню, вкладки, калькулятор, демо-бот, форма заявки
- `privacy.html`, `terms.html` — политика конфиденциальности и условия (шаблоны)

## Что заменить перед запуском

Найдите и замените во всех файлах:

| Заглушка | На что заменить |
|---|---|
| `[Название]` | название вашей компании |
| `[Юридическое название компании]`, `[номер]`, `[Эмират / free zone]`, `[адрес]`, `[дата]` | данные из trade license |
| `971000000000` / `+971 00 000 0000` | ваш номер WhatsApp и телефона |
| `hello@example.com` | ваш email |
| `[0 000]` в разделе «Пакеты» | ваши цены |

В `script.js` в блоке `CONFIG`:
- `whatsapp` — номер без `+`;
- `formEndpoint` — адрес формы [Formspree](https://formspree.io) (бесплатно), чтобы заявки приходили на почту. Пока поле пустое, форма открывает WhatsApp с текстом заявки.

## Важно

- Платформы указаны текстом в блоке «Платформы, с которыми мы работаем», без логотипов и без слова «партнёр». Логотипы и «Наши партнёры» добавляйте только после получения официального партнёрского статуса.
- Раздел с кейсами и отзывами появится, когда будут реальные проекты. Не публикуйте выдуманные отзывы.
- `privacy.html` и `terms.html` — шаблоны, их стоит проверить у юриста в ОАЭ.

## Публикация

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
